# Plans 2–4 — The app: UI, 48 h outlook, regions/models/widget/notifications

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The user-facing Android app on top of Plan 1's engine: Now (Nowcast | Next 48 h), Map, Settings, first-run key screen, the on-device 48 h outlook (local GBM, ICON-D2-EPS fallback), regions editor, model upload, background refresh, "rain in N min" notification and a Glance widget.

**Architecture:** Pure logic lives in the JVM `engine/` module (Outlook, Render, Validate) and in plain-Kotlin app files with no Android imports (Settings, Alerts), so all of it is JUnit-tested on the desktop. The app is one Activity with Compose, a single `Repo` singleton owned by the `Application` that runs cycles and exposes a `StateFlow<UiState>`; screens are stateless-ish composables over that state. No DI framework, no navigation library (three tabs + one sub-page are a `when`).

**Tech Stack:** Plan 1's stack, plus (versions checked on Google Maven / Maven Central 2026-10-27): Compose BOM `2026.06.01` (ui 1.11.4 — BOM 2026.08+ and lifecycle 2.11 require compileSdk 37, which the Global Constraints rule out), Kotlin compose compiler plugin `2.4.20`, `androidx.activity:activity-compose:1.13.0`, `androidx.lifecycle:lifecycle-runtime-compose:2.10.0`, `org.maplibre.gl:android-sdk:13.7.1`, `androidx.work:work-runtime-ktx:2.12.0`, `androidx.glance:glance-appwidget:1.2.0` + `glance-material3:1.2.0`. **Not** `androidx.security:security-crypto`: every API in it is deprecated since 1.1.0-alpha07 "in favour of existing platform APIs and direct use of Android Keystore" (release notes via context7), so keys are AES-GCM-encrypted with an Android Keystore key and stored in ordinary SharedPreferences.

## Global Constraints

- minSdk 26, compileSdk 36, targetSdk 36; AGP 9.3.3, Gradle 9.8.2, Kotlin 2.4.20, JDK 21. Test device: x86_64 AVD `nowcast-ui`, SDK in `~/Android`.
- Rain threshold 0.1 mm/h everywhere; outlook "wet" = > 0.1 mm per 30 min.
- **Switch, not blend:** a bar comes from the nowcast iff the nowcast's point curve covers the whole bar (≈ the first hour); every other bar comes from the outlook.
- Outlook features exactly as `app/src/main/assets/outlook/outlook_gbm.json` / `outlook_train.assemble`: 3 models, 3 prev-hour, 3 next-hour, mean, max, sin/cos hour (UTC, hour of the hour-END timestamp), sin/cos day-of-year (`(doy-1)/365.25·2π`), lat, lon, lead_bucket (`0` if lead < 12 h else `1`). ONNX input `x` `(n,18)` float32, output `quantiles` `(n,9)`; sort and clip at 0.
- Open-Meteo hourly values are the sum over the hour ENDING at the timestamp; each hour is split into two equal 30-min bars.
- ORD key only in the `apikey` header; never logged, never committed. Outlook is never fabricated: missing hours are gaps.
- Model validation: 12 → 12 frames, finite, ≤ 500 mm/h (Plan 1's `SmaatModel.forecast` refusals).
- `engine/src/main/kotlin/nowcast/engine/UiStubs.kt` holds ONLY Task 9's `Forecast` and `Nowcaster` with Task 9's exact signatures; it is deleted at merge with the engine branch.

### Task 3: `Outlook.kt` — the 48 h outlook

**Files:** Create `engine/src/main/kotlin/nowcast/engine/Outlook.kt`; Test `OutlookTest.kt`.

**Interfaces (produces):**
```kotlin
class OutlookException(msg: String) : Exception(msg)
enum class BarSource { NOWCAST, MODEL, ENSEMBLE }
class Bar(val start: Instant, val mm: Double, val p10: Double, val p90: Double, val probability: Double, val source: BarSource) { val end: Instant }
class Hourly(val time: List<Instant>, val series: Map<String, DoubleArray>)   // time = hour END, NaN = missing
class Outlook(val bars: List<Bar>, val fetched: Instant, val usedModel: Boolean, val note: String?)
object OutlookFeatures { val MODELS: List<String>; val NAMES: List<String>; fun row(h: Hourly, j: Int, lat: Double, lon: Double, now: Instant): FloatArray? }
class OutlookModel(bytes: ByteArray) : AutoCloseable { fun quantiles(x: List<FloatArray>): List<DoubleArray> }
object OpenMeteo { fun parse(json: String): Hourly; fun deterministic(lat: Double, lon: Double): Hourly; fun ensemble(lat: Double, lon: Double): Hourly }
object OutlookBars {
    const val N = 96; const val WET_MM = 0.1
    fun fromQuantiles(hourEnd: Instant, q: DoubleArray): List<Bar>
    fun fromMembers(hourEnd: Instant, members: DoubleArray): List<Bar>
    fun assemble(det: Hourly?, ens: Hourly?, model: ((List<FloatArray>) -> List<DoubleArray>)?, lat: Double, lon: Double, now: Instant): Outlook
    fun join(outlook: Outlook?, point: PointForecast?, issued: Instant?, now: Instant): List<Bar?>   // N bars from floor30(now)
    fun sentence(bars: List<Bar?>, zone: ZoneId): String
    fun label(b: Bar, zone: ZoneId): String    // "Tue 14:00–14:30 · 60% · 0.4–1.8 mm"
}
fun fetchOutlook(lat: Double, lon: Double, model: OutlookModel?, now: Instant = Instant.now()): Outlook
```
Behaviour: deterministic fetch `https://api.open-meteo.com/v1/forecast?latitude&longitude&hourly=precipitation&models=icon_d2,icon_eu,ecmwf_ifs025&timezone=GMT&past_days=1&forecast_days=3` (keys `precipitation_<model>`); ensemble `https://ensemble-api.open-meteo.com/v1/ensemble?…&models=icon_d2&hourly=precipitation&timezone=GMT&forecast_days=3` (keys `precipitation`, `precipitation_member01..19` = 20 members). Window = hours ending in `(floor30(now), floor30(now)+48 h + 1 h]`. GBM for every hour whose row is complete; if the model is absent, throws, or no row is complete → note "Local outlook model unavailable — showing ICON-D2-EPS"; hours the GBM did not cover come from EPS members; nothing at all → `OutlookException`. Bars: halves = values/2; mm = mean(halves); GBM p10/p90 = halves[0]/halves[8]; EPS p10/p90 = `percentile(halves, 10/90)`; probability = share of halves > 0.1. Nowcast bar for `[s, s+30)` iff `issued+minutes.first ≤ s` and `s+30 ≤ issued+minutes.last`: mm = Σ values/60, p10/p90 = Σ p10/60, Σ p90/60, probability = max minute probability (the same "chance" the Nowcast tab shows, so the tabs agree).
